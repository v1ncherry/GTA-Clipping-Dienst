Streamer hinzufügen

Verbundene Accounts

YouTube

Einmalig auf dem Rechner ausführen, auf dem der Clipper läuft (öffnet den Google-Login im Browser):

python -m clipper connect youtube

Läuft der Clipper auf einem anderen Rechner: --manual anhängen und die Weiterleitungs-URL einfügen.

TikTok

1. Login-Link öffnen und Account freigeben. 2. Die URL, auf die TikTok weiterleitet, hier einfügen.

Instagram

Long-Lived Access Token aus der Meta-App (Instagram API mit Instagram-Login) einfügen. Account muss Business oder Creator sein.

Facecam einzeichnen –

Rahmen mit der Maus um die Facecam ziehen. Wird für alle Clips dieses Streamers benutzt.
